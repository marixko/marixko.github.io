## VC dimension

The bound of the previous lecture held for finite classes and depended on
$$\log\lvert\mathcal{H}\rvert$$. But the classes we use (all hyperplanes, all
trees of a given depth) are **infinite**. The Vapnik-Chervonenkis dimension
measures the capacity of such classes in a way that does not depend on counting
them.

### Hypothesis class and dichotomies

Let $$\mathcal{H}$$ be a class of binary classifiers
$$f:\mathcal{X}\rightarrow\{0,1\}$$. Given a set of $$m$$ points
$$\{x_1,\ldots,x_m\}$$, each $$f\in\mathcal{H}$$ produces a label vector
$$\big(f(x_1),\ldots,f(x_m)\big)\in\{0,1\}^{m}$$. Each distinct vector is a
**dichotomy**. There are at most $$2^{m}$$ possible dichotomies, but
$$\mathcal{H}$$ may realize only some of them.

### Shattering

We say that $$\mathcal{H}$$ **shatters** the set $$\{x_1,\ldots,x_m\}$$ if it
realizes **all** $$2^{m}$$ dichotomies, that is, if for any assignment of labels
there is an $$f\in\mathcal{H}$$ that reproduces it. Shattering a set means that,
on those points, $$\mathcal{H}$$ has no restriction at all.

### Growth function and VC dimension

The **growth function** $$\Pi_{\mathcal{H}}(m)$$ is the maximum number of
dichotomies that $$\mathcal{H}$$ realizes on some set of $$m$$ points:

$$
\Pi_{\mathcal{H}}(m)=\max_{x_1,\ldots,x_m}\big\lvert\{(f(x_1),\ldots,f(x_m)):f\in\mathcal{H}\}\big\rvert\ \le\ 2^{m}.
$$

The **VC dimension** is the largest $$m$$ for which
$$\Pi_{\mathcal{H}}(m)=2^{m}$$, that is, the size of the largest set that
$$\mathcal{H}$$ can shatter:

$$
d_{\mathrm{VC}}(\mathcal{H})=\max\{\,m:\Pi_{\mathcal{H}}(m)=2^{m}\,\}.
$$

If $$\mathcal{H}$$ shatters sets of any size, $$d_{\mathrm{VC}}=\infty$$. It is
enough for **one** set of $$m$$ points to be shattered for
$$d_{\mathrm{VC}}\ge m$$; to show $$d_{\mathrm{VC}}<m$$ one must show that
**no** set of $$m$$ points can be shattered.

### The Sauer-Shelah lemma

The result that makes the VC dimension useful: as soon as $$m$$ passes
$$d_{\mathrm{VC}}$$, the growth function stops being exponential and becomes
**polynomial**. For $$m\ge d_{\mathrm{VC}}=:d$$,

$$
\Pi_{\mathcal{H}}(m)\ \le\ \sum_{i=0}^{d}\binom{m}{i}\ \le\ \left(\frac{e\,m}{d}\right)^{d}.
$$

It is this transition from $$2^{m}$$ to $$m^{d}$$ that will replace the
$$\log M$$ of the finite bound by $$d_{\mathrm{VC}}\log m$$ in the next lecture.

### Examples

| Class $$\mathcal{H}$$ | $$d_{\mathrm{VC}}$$ |
| --- | --- |
| Thresholds on $$\mathbb{R}$$, $$f(x)=\mathbf{1}[x>a]$$ | $$1$$ |
| Intervals on $$\mathbb{R}$$, $$f(x)=\mathbf{1}[a\le x\le b]$$ | $$2$$ |
| Halfspaces (linear classifiers) in $$\mathbb{R}^{d}$$ | $$d+1$$ |
| Axis-aligned rectangles in $$\mathbb{R}^{2}$$ | $$4$$ |
| $$f(x)=\mathbf{1}[\sin(\omega x)>0]$$, $$\omega$$ free | $$\infty$$ |

For halfspaces in $$\mathbb{R}^{d}$$, the VC dimension is $$d+1$$, which is
exactly the number of parameters of a hyperplane with intercept. The sine
example shows that **a single parameter** can give infinite capacity: counting
parameters is not the same as measuring capacity.

### Model capacity

The VC dimension is the formalization of the central question of this lecture:

> How many different patterns can a class of models represent?

It acts as an "effective number of parameters" for the purposes of
generalization. A class with large $$d_{\mathrm{VC}}$$ is flexible enough to
shatter many sets, which means low bias but high risk of overfitting. The bound
of lecture 3.5 will make this trade-off precise.
