Exiba Notebooks Jupyter com academia

Aprenda como blogar no academia usando notebooks Jupyter

Instale Python e Jupyter

Instale o Anaconda que inclui Python 3 e Jupyter notebook.

Ou, para usuários avançados, instale o Jupyter notebook com pip3 install jupyter.

Crie uma nova postagem no blog como de costume

Execute os seguintes comandos no seu Terminal, substituindo <MEU_DIRETÓRIO_DO_SITE> e minha-postagem pelo caminho do seu site academia e um nome para sua postagem (sem espaços):

cd <MEU_DIRETÓRIO_DO_SITE>
hugo new  --kind post post/minha-postagem
cd <MEU_DIRETÓRIO_DO_SITE>/content/post/minha-postagem/

Crie ou envie um notebook Jupyter

Execute o comando abaixo para iniciar o Jupyter na pasta da nova postagem. Depois, crie um novo notebook Jupyter (New > Python Notebook) ou envie um notebook existente.

jupyter notebook

Converta o notebook para Markdown

jupyter nbconvert Untitled.ipynb --to markdown --NbConvertApp.output_files_dir=.

# Copie o conteúdo de Untitled.md e adicione ao index.md:
cat Untitled.md | tee -a index.md

# Remova o arquivo temporário:
rm Untitled.md

Edite os metadados da sua postagem

Abra index.md no seu editor de texto e edite o título etc. no front matter conforme sua preferência.

Para definir uma imagem de destaque, coloque uma imagem chamada featured na pasta da sua postagem.

Para outras dicas, como usar matemática, veja o guia sobre escrever conteúdo com academia.
