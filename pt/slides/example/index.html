Fragmentos

Faça o conteúdo aparecer incrementalmente

{{% fragment %}} Um {{% /fragment %}}
{{% fragment %}} **Dois** {{% /fragment %}}
{{% fragment %}} Três {{% /fragment %}}

Pressione Espaço para ver!

Um fragmento pode aceitar dois parâmetros opcionais:

  • class: use um estilo personalizado (requer definição no CSS customizado)
  • weight: define a ordem de aparição do fragmento

Slide Personalizado

Personalize o estilo e o fundo do slide

{{< slide background-image="/img/boards.jpg" >}}
{{< slide background-color="#0000FF" >}}
{{< slide class="meu-estilo" >}}

Exemplo de CSS Personalizado

Vamos deixar os títulos na cor azul marinho.

Crie assets/css/reveal_custom.css com:

.reveal section h1,
.reveal section h2,
.reveal section h3 {
  color: navy;
}
