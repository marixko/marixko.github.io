O bloco básico

O neurônio artificial

Um neurônio recebe números de entrada, multiplica cada um por um peso, soma tudo com um viés e passa o resultado por uma função de ativação.

z = w₁·x₁ + w₂·x₂ + b
y = σ(z)

Os pesos dizem o quanto cada entrada importa. Aprender = ajustar esses pesos. Mexa nos controles ao lado.

Vetores

Um neurônio é um produto escalar

Juntamos as entradas num vetor x e os pesos num vetor w. A soma ponderada é o produto escalar:

z = w · x + b = Σᵢ wᵢ xᵢ + b

Exemplo: x = [2, 1, 3], w = [0.5, −1, 0.2], b = 0.1

z = 0.5·2 + (−1)·1 + 0.2·3 + 0.1
  = 1 − 1 + 0.6 + 0.1 = 0.7

Geometricamente, w · x = ‖w‖ ‖x‖ cos θ: o produto escalar mede o quanto dois vetores apontam na mesma direção. Ou seja, cada neurônio é um detector: ele "acende" quando a entrada se parece com o padrão guardado em seus pesos.

Profundidade

Redes em camadas

Organizamos neurônios em camadas. A saída de uma camada vira entrada da próxima.

  • As primeiras camadas detectam padrões simples (bordas, sílabas).
  • As mais profundas combinam esses padrões em ideias complexas (rostos, significado).
  • "Deep learning" = redes com muitas camadas.

Clique em "Propagar" para ver o sinal atravessar a rede.

Função de ativação · parte 1 de 3

Por que precisamos de uma função de ativação?

Pense na soma z como "quanta evidência" o neurônio juntou. A função de ativação é a regra de decisão: dada essa evidência, o quanto o neurônio deve "disparar"?

Mas o motivo principal é outro. Sem ativação, cada camada só faz multiplicar e somar. E empilhar contas lineares dá… outra conta linear:

camada 1: h = w₁x + b₁
camada 2: y = w₂h + b₂
         = (w₂w₁)x + (w₂b₁+b₂) ← ainda uma reta!

Com 2 ou 200 camadas, uma rede sem ativação equivale a uma única camada. Ela só consegue separar dados com uma linha reta. A ativação "dobra" o espaço e permite fronteiras curvas.

Explorando as principais funções

Linha cheia: f(z). Tracejada: derivada f′(z), que diz o quanto a saída muda quando z muda. É ela que permite o aprendizado (mais adiante).
Função de ativação · parte 3 de 3

Somando "dobras", desenhamos qualquer curva

Cada neurônio com ReLU contribui com uma dobra: uma função que é zero até certo ponto e depois sobe em linha reta.

f(x) = Σₖ aₖ · ReLU(x − cₖ)

Somando várias dobras, com pesos aₖ e posições cₖ diferentes, montamos uma curva aos pedaços. Mais neurônios = aproximação mais fiel.

É como desenhar um círculo com segmentos de reta: com 4 parece um quadrado; com 50 parece um círculo.

Isso é a intuição do Teorema da Aproximação Universal: uma rede com ativação não linear e neurônios suficientes pode aproximar qualquer função contínua.

Álgebra linear

Uma camada inteira = uma multiplicação de matriz

Cada linha da matriz W guarda os pesos de um neurônio. Multiplicar W pelo vetor de entrada calcula todos os neurônios da camada de uma vez:

h = σ( W x + b )
W: m × n · x: n · b, h: m

Uma camada com n entradas e m neurônios tem m·n + m parâmetros. Num LLM, uma única matriz de 4096 × 4096 já tem ~16,8 milhões de números.

Por isso GPUs são essenciais: elas multiplicam matrizes gigantes em paralelo.

Passe o mouse sobre um resultado para ver de qual linha ele vem.

Medindo o erro

Funções de perda

Para aprender, a rede precisa de um número que diga o quão errada ela está. Esse número é a perda (loss).

Compare a resposta certa y com o palpite da rede ŷ ("y chapéu"). Um jeito clássico é o erro quadrático médio:

L = (1/n) Σ (yᵢ − ŷᵢ)²
ex: y = 3, ŷ = 2.5 → L = (0.5)² = 0.25
  • Elevar ao quadrado deixa o erro sempre positivo.
  • Erros grandes pesam muito mais: errar por 2 custa 4; errar por 10 custa 100.
  • Perda zero = palpite perfeito. Treinar = buscar a menor perda possível.
Aprendizado

Gradiente descendente

  • Previsão: a rede faz um palpite.
  • Perda: medimos o quão errado foi o palpite.
  • Gradiente: calculamos a inclinação da perda em relação a cada peso.
  • Passo: andamos um pouco "ladeira abaixo".
w ← w − η · ∂L/∂w
η = taxa de aprendizado (tamanho do passo)

η pequeno: lento. η grande: pula o mínimo e oscila. Experimente!

Cálculo

Backpropagation = regra da cadeia

Como saber o efeito de um peso lá no início sobre a perda lá no fim? Usando a regra da cadeia: multiplicamos as derivadas de cada etapa, de trás para frente.

∂L/∂w = ∂L/∂z · ∂z/∂w

Exemplo: z = w·x + b, L = (z − y)², com x=2, w=3, b=1, y=10

ida: z = 3·2+1 = 7, L = (7−10)² = 9
∂L/∂z = 2(z−y) = −6 · ∂z/∂w = x = 2
∂L/∂w = (−6)(2) = −12
w ← 3 − 0.01·(−12) = 3.12 → L cai para 7.62

Tokens e embeddings

Redes só entendem números. Por isso o texto é quebrado em tokens (pedaços de palavras), e cada token vira um vetor de centenas ou milhares de números: o embedding.

Geometria do significado

Similaridade do cosseno

Para medir se dois embeddings têm significado parecido, comparamos a direção dos vetores:

cos(θ) = (a · b) / (‖a‖ ‖b‖)
1 = mesma direção · 0 = sem relação · −1 = opostos

A arquitetura Transformer

Atenção: quem olha para quem

O Transformer (2017) é a base de todos os LLMs modernos. Sua peça central é a autoatenção: cada token decide em quais outros tokens prestar atenção para entender o contexto.

Em "O gato subiu no muro porque ele estava assustado", a atenção liga "ele" a "gato".

Passe o mouse (ou toque) em uma palavra.

A fórmula da atenção

Query, Key, Value

Atenção(Q,K,V) = softmax( QKᵀ / √d ) · V

Como numa biblioteca: a Query é sua pergunta, cada livro tem uma Key (etiqueta) e um Value (conteúdo). Você lê mais os livros cujas etiquetas combinam com a pergunta.

  • Cada token gera q, k, v multiplicando seu embedding por matrizes aprendidas WQ, WK, WV.
  • q · k mede a compatibilidade; dividir por √d evita números grandes demais.
  • softmax transforma em pesos que somam 1.
  • A saída é a média dos v, ponderada por esses pesos.

Token "ele": q = [1.0, 0.8], d = 2

Na prática há várias "cabeças" de atenção em paralelo (multi-head), cada uma aprendendo um tipo de relação.

De pontuações a probabilidades

Softmax

A última camada de um LLM dá uma pontuação bruta (chamada logit) para cada token do vocabulário, que tem de 50 a 200 mil tokens. Essas pontuações podem ser negativas e não somam 1: ainda não são probabilidades.

A softmax faz essa conversão:

pᵢ = e^(zᵢ) / Σⱼ e^(zⱼ)
  • Passo 1: e^z deixa tudo positivo e amplia as diferenças: quem pontuou mais ganha bem mais.
  • Passo 2: dividir pela soma faz tudo somar 1, ou seja, 100%.

Uma pontuação 1 ponto maior vira uma probabilidade ~2,7× maior (e ≈ 2,718).

O botão de criatividade

Temperatura

O modelo sorteia o próximo token. A temperatura T decide o quanto o favorito leva vantagem: antes da softmax, cada pontuação é dividida por T.

azul = 3, nublado = 2 → diferença 1
T = 0.5: 6 e 4 → diferença 2 ← favorito dispara
T = 2: 1.5 e 1 → diferença 0.5 ← opções se aproximam

T baixa: previsível (código, fatos). T alta: criativo, mas pode perder o sentido.

O que um LLM realmente faz

Prever o próximo token

Um LLM é treinado para uma tarefa simples: dado um texto, prever o próximo token. Ele produz uma probabilidade para cada token possível, escolhe um, adiciona ao texto e repete.

Ajuste a temperatura (slide anterior) e gere de novo: com T baixa o texto sai quase sempre igual; com T alta, cada geração é diferente.

O objetivo de treino

A função que o LLM minimiza

A probabilidade de um texto inteiro é o produto das probabilidades de cada token, dado o que veio antes:

P(x₁…xₙ) = Πₜ P(xₜ | x₁…xₜ₋₁)

Para cada token, a perda é −log da probabilidade que o modelo deu ao token que realmente veio: se deu 90%, a perda é pequena (0.11); se deu 1%, é enorme (4.6). Errar com confiança sai caro. O treino minimiza a média sobre trilhões de tokens:

L = −(1/N) Σₜ log P(xₜ | x<ₜ)

E a perplexidade resume isso num número intuitivo: PPL = e^L, ou seja, "entre quantas opções o modelo hesita, em média". Quanto menor, melhor.

Probabilidades ilustrativas. O gradiente dessa perda, via backpropagation, ajusta bilhões de parâmetros.

ETAPA 1

Pré-treinamento

Humanos (e outros modelos) avaliam respostas; o modelo é reforçado a ser útil, honesto e seguro (RLHF e técnicas similares).

Escala importa: mais parâmetros, mais dados e mais computação tendem a gerar modelos mais capazes.
